# Vacina.Ai

> Assistente inteligente para análise, interpretação e gestão de cartões de vacinação.

---

## Sobre o Projeto

O **Vacina.Ai** é um assistente baseado em inteligência artificial desenvolvido para auxiliar profissionais de saúde, laboratórios e técnicos de imunização na análise e interpretação de cartões de vacinação.

A ferramenta permite extrair, organizar e padronizar informações vacinais a partir de imagens, PDFs ou dados digitais, além de fornecer suporte com base nos protocolos oficiais do Programa Nacional de Imunizações (PNI).

---

## Funcionalidades

- Leitura de cartões de vacinação (imagem, PDF ou digital)
- Extração automática de dados vacinais
- Organização e padronização das informações
- Interpretação de esquemas vacinais
- Identificação de doses em atraso
- Orientações sobre contraindicações
- Baseado em protocolos do Ministério da Saúde / PNI
---

## Tecnologias Utilizadas

- Node.js / JavaScript
- HTML, CSS, JavaScript (Frontend)
- APIs de IA (processamento de linguagem natural)
- OCR (leitura de imagens)
- Integrações com sistemas laboratoriais
